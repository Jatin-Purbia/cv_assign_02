# Captured photos and reference masks

The 10 user-provided photos are organized as:

- `original/`: original photos.
- `images_256/`: 256x256 PNGs resized with INTER_AREA.
- `masks_256/`: matching 256x256 binary PNG reference masks (object 255, background 0).
- `model_predictions/`: latest trained-model masks, baseline comparison and prediction provenance.

The masks were generated by pretrained EfficientSAM-Ti with assistant-selected
boxes/points. They are AI-generated reference masks, not manually drawn ground
truth. `mask_provenance.json` records the model, prompts, hashes and limitations;
`source_manifest.json` records the photo sources. `reference_comparison.png`
shows the prompted photos, reference overlays and binary masks.

The assignment's manual-annotation requirement is not satisfied by these masks.
Capture details and condition coverage have not yet been supplied. Do not use
these photos or reference masks for training or model selection.
